# Sneakernet — logo pack

Interlocked-hexagon mark + lowercase IBM Plex Mono wordmark.

## Palette
- Ink `#1c1a14` · Cream `#f6f2e7` · Amber `#e69f4b` (accent) · Clay `#c2603e` (unread) · Dark `#14130f`

## svg/  (vector — wordmark font embedded, no install needed)
- `mark-ink`, `mark-cream`, `mark-twotone`, `mark-twotone-cream` — the mark
- `lockup-horizontal`, `lockup-accent-tail`, `lockup-dark` — mark + wordmark
- `icon` — app icon (mark on dark tile)
- `favicon-unread`, `favicon-unread-dark` — unread state (clay+amber, woven), light/dark themes
- `favicon-dark-read`, `favicon-dark-unread` — dark-tile favicons, both states

## favicons/  (PNG, 16–256 px)
- `favicon-{16,32,48,64}` — resting, transparent
- `favicon-unread-*` — unread, transparent (ink outline)
- `favicon-unread-dark-*` — unread, transparent (cream outline, for dark themes)
- `favicon-dark-read-*` / `favicon-dark-unread-*` — dark tile, both states

The unread mark fills the first link clay and the second amber, woven so the
colors cross at the overlap (interlinked, not stacked).
